# How to Reassess Your Chess - Interactive Application

Interactive web application for personal study of the book "How to Reassess Your Chess" (4th Edition) by Jeremy Silman.

## Features

- **Table of contents navigation**: Quick access to the 9 main parts of the book
- **Section-by-section reading**: Navigate through the book's logical sections
- **Inline diagrams**: Chessboards appear directly in the text next to each diagram
- **Interactive chessboard**: Click "Enlarge" to play through moves and analyze a position
- **Integrated search**: Quickly find concepts or specific positions
- **Keyboard navigation**: Arrow keys ← → to move forward/backward, Esc to close the board

## How to use

### Start the application

1. Install dependencies and start the Vite dev server:
   ```bash
   cd chess-app
   npm install
   npm run dev
   ```

2. Open your browser and go to:
   ```
   http://localhost:5173
   ```

3. Production build (optional):
   ```bash
   npm run build      # generates dist/ (public/ is regenerated by prebuild)
   npm run preview    # serves the build (http://localhost:4173)
   ```

### Navigation

- **Side menu** (☰): Click to open/close the navigation menu
- **Table of contents**: Click a part or chapter to jump directly to it
- **Navigation buttons**: Use "← Previous" and "Next →" to move through the book
- **Progress bar**: Visualize your progress through the book

### Inline diagrams

Each diagram in the book appears directly in the text as an interactive chessboard.

- Positions come from the integrated PGN studies in `data/diagrams.json`
- Use the buttons under the board to navigate through recorded moves
- Click "Enlarge" to open the diagram in modal mode
- Diagrams with unknown positions display a "default position" badge

### Search

- Use the search bar at the top right
- Type a keyword (e.g. "Knight", "bishop", "pawn structure")
- Click a result to navigate to that passage

## Docker / Portainer

Optional deployment of the fully static application via Docker: the
multi-stage Dockerfile installs dependencies with `npm ci`, builds
`dist/` with `npm run build` (prebuild copies data/ and cm-chessboard
into public/), then serves the result with Nginx (internal port 80; no
backend, env or volume required).

Manual build and run (from the project root):
```bash
docker build -t silman-chess-app ./chess-app
docker run -d -p 5174:80 --restart unless-stopped --name silman-chess silman-chess-app
```

Or with docker compose (from the root, where `docker-compose.yml` is located):
```bash
docker compose up -d --build
```

Then open: http://localhost:5174

### Portainer

1. Go to **Stacks** > **Add stack**
2. Choose **Web editor** (paste the compose) or **Repository** (point to the
   repository containing `docker-compose.yml`)
3. Click **Deploy**: the `silman-chess` container is created with
   `restart: unless-stopped`

HTTPS: handle via an external reverse proxy (Traefik, Nginx, Caddy...);
the Nginx image contains no TLS.

## Keyboard shortcuts

- `←` (Left arrow): Previous section
- `→` (Right arrow): Next section
- `Esc`: Close modal chessboard
- `Home`/`End`: First/last position of a diagram
- `←`/`→` (with focused diagram): Navigate through moves

## Book data

- **Total sections**: one per EPUB H2 (132 after splitting sections > 15,000 characters)
- **Unique diagrams**: 432 (714 occurrences in the text)
- **FEN coverage**: 100 % (429 via Study parsing + 3 via exclusive manual overrides, 4 overrides total; diagrams without FEN would show the starting position with a warning badge)
- **Diagrams with navigable moves**: 299 (+ 235 with Study variations)
- **The complete book text is included** for personal fair use

3. **Part Three**: Rooks
4. **Part Four**: Psychological Meanderings
5. **Part Five**: Target Consciousness
6. **Part Six**: Statics vs. Dynamics
7. **Part Seven**: Space
8. **Part Eight**: Passed Pawns
9. **Part Nine**: Other Imbalances

## Data generation scripts

- `silman_parser/` : parser package (one module per responsibility:
  `epub_ingest` (EPUB source, spine order), `san`, `segmentation`,
  `html_render`, `diagram_context`, `study`, `overrides`, `build`)

To regenerate the data (from the project root):
```bash
python3 -m silman_parser.build
```

## Source of the text (EPUB)

The text comes from the native EPUB **How to Reassess Your Chess 4th ed - Silman.epub**,
read in the order of the `content.opf` spine. Sections are the H2s (H3s rendered as
`<h3>` in the content), diagram blocks (`<p class="diagram-number">Diagram N</p>`)
become `<div class="diagram-inline" data-diagram="N">`, and `<span class="bold">`
move spans become `<div class="game-notation">`. FENs come from the PGN studies
(`pgn_studies/`), not from the EPUB.
